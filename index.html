Personal project

built and run on-premise

Customer 360 Lakehouse — retail banking

Iceberg · MinIO · Spark · Trino · Airflow · Docker
  • Customer data lived in two disconnected systems — Oracle core banking and a PostgreSQL CRM + card platform — so nobody could see one customer whole. Built an end-to-end lakehouse on Iceberg + MinIO that unifies all eight source tables under a Bronze → Silver → Gold medallion model.
  • SCD Type 2 on the customer dimension keeps the full history of segment and address changes; Type 1 for accounts, products and branches. Daily incremental load keyed on updated_at — no full reloads.
  • The Gold mart is one row per customer with 25+ KPIs, automatic RFM segmentation (Champions / Loyal / At Risk / Lost) and three cross-sell flags marketing can target directly.
  • Airflow runs it at 2 AM with retries and audit logging — re-running a day produces zero duplicates. The whole stack runs on Docker Compose, on-premise, at zero cloud cost, with Trino serving SQL so nothing queries production.
